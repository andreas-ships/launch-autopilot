# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-19

### Added
- `launch-autopilot` skill with commands: go, setup, strategy, assets, video, poster, queue, today, week, new-feature, refill, review, audit, export, schedule.
- `scripts/contentq.py`: JSON content queue with inject, due, status, flag, CSV and ICS export, selftest.
- `scripts/render.py`: HTML templates to PNG/PDF via Playwright, with brand data and QR codes.
- `scripts/video.py`: storyboard JSON to MP4 with burned-in captions and optional music.
- HTML templates: social post, carousel slide, OG image, poster, story scene.
- Vendored MIT marketing guides from coreyhaines31/marketingskills.
